# Jadu

> A curated collection of Claude Code custom commands — open for public use, contribution, and remixing.

## Overview

Jadu (جادو — "magic") is a public template repository of Claude Code skills (slash commands) that streamline common development workflows. It is designed to be cloned, forked, or used as inspiration for building your own Claude command set. Anyone can contribute new commands or improvements via pull request.

## Tech Stack

| Layer | Choice |

## Conventions

- **Branching:** No formal strategy — direct commits and PRs welcome
- **Code style:** Follow existing skill file format and naming conventions
- **Review:** All PRs are automatically reviewed by Claude; all public contributions are welcome

## Notes

- Skills follow the `bobo-` prefix naming convention (e.g. `bobo-init-project`, `bobo-wrap-it-up`)
- The repo serves as both a working toolkit and a public template others can fork and adapt
