# جادو (Jadu)

مجموعه‌ای از اسکیل‌های سفارشی Claude Code برای جلسات کاری ساختارمند و پربازده. ریپو را فورک کنید، فایل‌ها را در پروژه‌تان بریزید، و دستورات بلافاصله در Claude Code در دسترس خواهند بود.

---

## اسکیل‌های موجود

| دستور | کارایی |
|---|---|
| `/bobo-study-project` | شروع جلسه — وضعیت پروژه را می‌خواند، لیست وظایف را با زیروظایف گسترش می‌دهد، و تایمرهای ۳۰ و ۶۰ دقیقه‌ای تمرکز تنظیم می‌کند |
| `/bobo-init-project` | ویزارد راه‌اندازی پروژه — یک‌بار سوالات را می‌پرسد و فایل‌های `CLAUDE.md`، `TASKS.md` و `WORKLOG.md` را می‌نویسد |
| `/bobo-wrap-it-up` | پایان جلسه — ورک‌لاگ را به‌روز می‌کند، یادداشت‌های معلق را ثبت می‌کند، و پروژه را آماده ادامه می‌گذارد |
| `/bobo-todo` | مدیریت وظایف از طریق مکالمه — اضافه کردن، به‌روزرسانی و تکمیل وظایف در `TASKS.md` بدون ویرایش مستقیم فایل |
| `/bobo-push` | Stage کردن تغییرات، نوشتن پیام کامیت، و پوش به شاخه جاری در یک مرحله |

---

## نحوه استفاده

### گزینه ۱ — به ازای هر پروژه (توصیه‌شده)

فایل‌های اسکیل موردنظر را در دایرکتوری `.claude/commands/` پروژه‌تان کپی کنید:

```bash
cp .claude/commands/bobo-study-project.md /your-project/.claude/commands/
```

دستور از آن پس داخل آن پروژه در دسترس خواهد بود.

### گزینه ۲ — سراسری (همه پروژه‌ها)

در دایرکتوری دستورات کاربر کپی کنید:

```bash
cp .claude/commands/bobo-*.md ~/.claude/commands/
```

دستورات در هر جلسه Claude Code در دسترس خواهند بود.

---

## سفارشی‌سازی

- **تغییر پیشوند** — پیشوند `bobo-` اختیاری است. فایل‌ها را به هر نامی که دوست دارید تغییر دهید (`/start`، `/push`، `/done`) و Claude Code نام‌های جدید را تشخیص خواهد داد.
- **ویرایش اسکیل** — هر فایل یک Markdown ساده است. مراحل، لحن، یا ساختار را متناسب با جریان کاری خود تغییر دهید.
- **اضافه کردن اسکیل جدید** — یک فایل `.md` جدید در `.claude/commands/` بسازید تا بلافاصله به یک slash command تبدیل شود.
