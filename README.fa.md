# جادو (Jadu)

مجموعه‌ای از اسکیل‌های سفارشی Claude Code برای جلسات کاری ساختارمند و پربازده. ریپو را فورک کنید، فایل‌ها را در پروژه‌تان بریزید، و دستورات بلافاصله در Claude Code در دسترس خواهند بود.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## اسکیل‌های موجود

| دستور | کارایی |
|---|---|
| `/jadu-bidar` | شروع جلسه — وضعیت پروژه را می‌خواند، لیست وظایف را با زیروظایف گسترش می‌دهد، و تایمرهای ۳۰ و ۶۰ دقیقه‌ای تمرکز تنظیم می‌کند |
| `/jadu-zad` | ویزارد راه‌اندازی پروژه — یک‌بار سوالات را می‌پرسد و فایل‌های `PROJECT.md`، `CLAUDE.md` و `TASKS.md` را می‌نویسد |
| `/jadu-tamam` | پایان جلسه — یک خلاصه فشرده می‌نویسد و همه به‌روزرسانی‌های مستندات را به یک agent پس‌زمینه واگذار می‌کند تا context کوچک بماند |
| `/jadu-kar` | مدیریت وظایف از طریق مکالمه — اضافه کردن، به‌روزرسانی و تکمیل وظایف در `TASKS.md` بدون ویرایش مستقیم فایل |
| `/jadu-push` | Stage کردن تغییرات، نوشتن پیام کامیت، و پوش به شاخه جاری در یک مرحله |

## نحوه استفاده

### گزینه ۱ — به ازای هر پروژه (توصیه‌شده)

فایل‌های اسکیل موردنظر را در دایرکتوری `.claude/commands/` پروژه‌تان کپی کنید:

```bash
cp .claude/commands/jadu-bidar.md /your-project/.claude/commands/
```

دستور از آن پس داخل آن پروژه در دسترس خواهد بود.

### گزینه ۲ — سراسری (همه پروژه‌ها)

در دایرکتوری دستورات کاربر کپی کنید:

```bash
cp .claude/commands/jadu-*.md ~/.claude/commands/
```

دستورات در هر جلسه Claude Code در دسترس خواهند بود.

## سفارشی‌سازی

- **تغییر پیشوند** — پیشوند `jadu-` اختیاری است. فایل‌ها را به هر نامی که دوست دارید تغییر دهید (`/start`، `/push`، `/done`) و Claude Code نام‌های جدید را تشخیص خواهد داد.
- **ویرایش اسکیل** — هر فایل یک Markdown ساده است. مراحل، لحن، یا ساختار را متناسب با جریان کاری خود تغییر دهید.
- **اضافه کردن اسکیل جدید** — یک فایل `.md` جدید در `.claude/commands/` بسازید تا بلافاصله به یک slash command تبدیل شود.

## اختیاری: هشدار صوتی

`/jadu-bidar` می‌تواند در هر یادآور تمرکز یک صدا پخش کند. به `ffplay` (بخشی از `ffmpeg`) و دو فایل صوتی در مسیر `~/.claude/sounds/` نیاز دارد.

این ریپو شامل فایل‌های صوتی پیش‌فرض است:

```bash
# نصب ffmpeg (اگر نصب نیست)
# macOS:  brew install ffmpeg
# Ubuntu: sudo apt install ffmpeg

# کپی فایل‌های صوتی
mkdir -p ~/.claude/sounds
cp sounds/30.mp3 ~/.claude/sounds/
cp sounds/60.mp3 ~/.claude/sounds/
```

اگر فایل‌ها یا `ffplay` موجود نباشند، اسکیل بدون صدا ادامه می‌دهد — فقط push notification ارسال می‌شود.
